# Sinaptia Educação Corporativa

Site institucional estático para publicação no GitHub Pages.

## Antes de publicar

1. Substitua `contato@sinaptia.com.br` pelo e-mail oficial.
2. Substitua o número do WhatsApp no link `wa.me`.
3. Confirme textos, cidade atendida e canais de contato.
4. Ative o GitHub Pages nas configurações do repositório.
